## 小游戏

- **[森林斗兽棋](https://github.com/Aimer779/jungle-chess)**：手绘风明棋，支持人机与双人同屏。[试玩](https://aimer779.github.io/jungle-chess/)
- **[球球炼金室](https://github.com/Aimer779/gel-lab)**：按住注胶，松手凝固，挑战恰到好处的手感。[试玩](https://aimer779.github.io/gel-lab/)
- **[郝哥求生指南](https://github.com/Aimer779/river-crossing)**：把经典过河谜题，变成一场熟悉的整活。[试玩](https://river-crossing-rosy.vercel.app/)
- **[Snap Snake](https://github.com/Aimer779/snap-snake)**：发条玩具蛇的三分钟混战，支持本地运行与局域网对战。
- **[恶魔轮盘 Web](https://github.com/Aimer779/buckshot-roulette)**：与 AI 庄家斗智的同人网页实现，仓库提供运行说明。
- **[帮他修一下](https://github.com/Aimer779/bang-ta-xiu-yixia)**：交互式剪指甲整活页。
- **[Ecliptic Path](https://github.com/Aimer779/ecliptic-path)**：更早的一次游戏实验。

## 小工具

- **[润图 SoftShot](https://github.com/Aimer779/runtu)**：给截图加背景、留白、圆角和阴影，再导出 PNG。
- **[ASCII GIF 工作台](https://github.com/Aimer779/404-copy)**：把 GIF 转成可调节的字符动画。[打开](https://aimer779.github.io/404-copy/tools/ascii-gif/demo/)
- **[字间 Glyph Studio](https://github.com/Aimer779/glyph-studio)**：编辑文字背景、渐变配色、波纹和动画。
- **[ima-note-cli](https://github.com/Aimer779/ima-note-cli)**：从终端搜索、读取和写入 IMA 笔记与知识库，也提供 Agent Skill。
- **[逍遥游](https://github.com/Aimer779/dsh-xiaoyaoyou)**：为 DeepSeek Harness 新建会话页添加文字水面背景。[安装](https://github.com/Aimer779/dsh-xiaoyaoyou/releases)

## 交互实验

- **[Soft Pudding](https://github.com/Aimer779/pudding-lab)**：抓取、轻戳、松手回弹的软体布丁，需要 WebGPU。[体验](https://aimer779.github.io/pudding-lab/)
- **[Voice Orb](https://github.com/Aimer779/codex-voice-orb-study)**：用声音频谱驱动 WebGL 圆球的呼吸与流动。[体验](https://aimer779.github.io/codex-voice-orb-study/)
- **[大头儿子年份变迁](https://github.com/Aimer779/datou-timeline)**：拖动时间标尺，探索角色形象的变化。[体验](https://datou-timeline.pages.dev/)
- **[脚踏缝纫机](https://github.com/Aimer779/sewing-machine-demo)**：可以操作的机械原理演示。
- **[Tesseract](https://github.com/Aimer779/interstellar-tesseract)**：受《星际穿越》启发的空间探索实验。
